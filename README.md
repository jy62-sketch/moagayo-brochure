# 모아가요 브로셔

[모아가요(moagayo)](https://moagayo-trip-app.vercel.app) 프로젝트의 **문제 정의 · 근거(출처 포함) · 해결 방안 · 제작 회고**를 담은 상호작용 브로셔예요. 앱 저장소(`moagayo-trip-app`)와는 별개로 관리해요.

## 열어 보기

- 공개 주소: https://moagayo-brochure.vercel.app/

- 파일 하나(`index.html`)에 스타일·스크립트·이미지·설문 데이터가 모두 들어 있어서, 더블클릭하거나 메일로 전달해도 열려요.
- 글꼴(Pretendard)만 인터넷에서 불러오고, 없으면 기본 글꼴로 보여요.
- 인쇄(PDF 저장)하면 모든 탭 내용이 펼쳐져요.

## 배포 (정적 사이트, 빌드 없음)

Vercel에서 **Add New → Project**로 이 저장소를 가져오고 Framework Preset은 `Other`, 빌드 명령과 출력 폴더는 비워 둔 채 Deploy하면 돼요. `index.html`의 `og:image`·`og:url`·`canonical`은 공개 주소(`https://moagayo-brochure.vercel.app/`)로 맞춰 두었어요. 주소를 바꾸면 이 세 곳도 함께 바꿔야 링크 미리보기가 보여요.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 브로셔 본문 (한 파일) |
| `og.jpg` | 링크 미리보기 이미지 (1200×630) |

## 자료에 대해

- **데스크 리서치:** 한국리서치, 마이리얼트립 고객센터, 마일모아, 여지앱. 링크와 확인일은 페이지 맨 아래 "출처"에 있어요.
- **설문:** 2026.10.8~9 구글폼, 응답 36명 중 분석 34명. 페이지의 차트에는 객관식 답만 이름 없이 옮겼고, 응답 원본 파일은 이 저장소에 없어요.
- **화면 그림:** 배포된 앱에서 직접 찍은 화면이에요. 샘플 여행방과 샘플 티켓은 모두 예시용 가상 데이터예요.
